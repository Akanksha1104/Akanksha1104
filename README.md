## 🚀 Featured Projects

### 🧮 [Scientific Calculator](https://github.com/Akanksha1104/scientific-calculator)
Full-stack scientific calculator with an **Angular** frontend and a **Spring Boot** REST API.
- Evaluates complete expressions with correct operator precedence and brackets, e.g. `2sin(30)+√(16)×π`
- Trigonometric, inverse and hyperbolic functions with **DEG / RAD** mode, logs, powers, roots, factorial
- Custom **recursive-descent expression parser** written in Java, with JUnit tests
- Calculation history, Ans key, keyboard support and clear error messages

`Java 17` `Spring Boot 3` `Angular 18` `TypeScript` `REST API` `JUnit`

`Java 21` `Spring Boot` `Spring MVC` `Thymeleaf` `Spring Data JPA` `MySQL`
